# 灯效对照：AWCC → NightGlow

调查日期：2026-11-27。机器：Alienware x16 R2 笔记本，外加一只 Alienware 610M 无线鼠标（2.4GHz 接收器）。

**调查方法（只看不改）：** 打开厂商控制中心（AWCC）的 AlienFX 灯光页，读取界面上能看到的内容。下拉列表里的灯效名称是通过 Windows 无障碍接口（UI Automation）读出来的：只展开和收起列表，没有选中其他项。整个过程没有切换灯效，没有保存预设，也没有改任何设置（包括散热和性能）。下面都是自己的话，没有复制 AWCC 的代码、图片、图标或声音。

## 1. 在 AWCC 里看到的灯光功能

### 设备

- **笔记本**：AWCC 把整台笔记本当成一个灯光区域，没有把键盘、背部灯带、徽标分开。
- **610M 鼠标**：显示连接方式（2.4GHz）和电量。
- **"选择所有设备"按钮**：一次编辑全部设备。

### 每个设备的灯效列表

| 设备 | 灯效（按 AWCC 下拉列表的顺序） |
|---|---|
| 笔记本 | 变形、脉冲、颜色、闪烁、频谱、彩虹波动、静态默认蓝色（7 个） |
| 610M 鼠标 | 变形、脉冲、颜色、闪烁、频谱、静态默认蓝色、Color Wave、Blue Logo（8 个；最后两个在中文界面里没有翻译） |

鼠标没有"彩虹波动"，多出"Color Wave"和"Blue Logo"。

### 参数

- **当前灯效"颜色"的编辑面板：**
  - 1 个颜色：色轮，加上红、绿、蓝三个输入框（各 0–255）。
  - 12 个自定义颜色槽和 12 个预设颜色。
  - 一个亮度滑块（0–100）。
- **AWCC 的效果数据里还有其他字段。** 通过无障碍接口读到的当前效果，除了颜色和亮度，还带着这些字段：触发事件（当前是"静态"）、速度、时长、方向、角度。所以 AWCC 的灯效支持调速度、时长、方向和角度。
- **没看到：** 具体哪个灯效显示哪些滑块、范围多少。要看到这些，得在编辑器里切换到那个灯效，而这次规定不切换（换效果的操作也被自动安全检查拦下了）。

### 全局功能

- **系统照明模式：** 三选一，"变亮 / 变黑 / 变暗"，当前是"变亮"。
- **AlienFX 预设：** 预设有名字（当前是"系统默认"），编辑后选"保存预设"或"取消"。
- **设置 › 全局预设 › 灯光预设开关：**
  - "系统"：所有场景用同一套灯光（当前设置）。
  - "每个游戏"：检测到游戏时自动切换灯光；默认按游戏封面的主色自动生成一套灯光。
- **设置 › 隐藏模式：** 一键关掉所有 AlienFX 灯光，同时切到安静的散热预设。当前是关闭。
- **库（游戏库）：** 按游戏绑定预设的入口。

### 这台机器上没有的

- 按键反应、随音乐变化、随温度变色：AlienFX 页面里都没有。
- 按电源状态（接电 / 电池 / 睡眠）分别设灯光：没有单独选项，只有上面的系统照明模式和隐藏模式。
- 单独设置某个灯区：AWCC 只能整机设置。

## 2. 对照表

"本次新增"指这次提交加进 NightGlow 的功能。

| AWCC 灯效 / 功能 | 设备 | NightGlow 对应 | 状态 |
|---|---|---|---|
| 颜色 | 笔记本、鼠标 | 静态 `static`（硬件：键盘 v5 static；机身灯 color 动作） | 已有 |
| 变形 | 笔记本、鼠标 | 渐变 `morph`（硬件：键盘 v5 morph=9；机身灯 morph 动作；2 色） | 已有 |
| 脉冲 | 笔记本、鼠标 | 脉冲 `pulse`（硬件：键盘 v5 pulse=8；机身灯 pulse 动作） | 已有 |
| 闪烁 | 笔记本、鼠标 | 最接近的是脉冲 `pulse` 或呼吸 `breathing`（硬件） | 近似：没看到 AWCC 的实际动画，不能确定对应哪一个 |
| 频谱 | 笔记本、鼠标 | 光谱循环 `spectrum`（硬件：键盘 v5 rainbow=14；机身灯 rainbow 动作） | 已有 |
| 彩虹波动 | 笔记本 | 彩虹波 `rainbow-wave`（硬件：键盘 v5 side wave + 光谱色；机身灯 spectrum 动作）；软件彩虹波 `sw-wave` | 已有；软件版的方向是本次新增 |
| 静态默认蓝色 | 笔记本、鼠标 | 默认蓝 `default-blue`（硬件静态，固定蓝色；色值是 NightGlow 自己选的） | **本次新增** |
| Color Wave | 鼠标 | 软件双色波 `sw-color-wave`（两种颜色按灯区顺序流动，可调方向）；键盘另有硬件双色波 `dual-wave` | 机身灯和键盘：**本次新增**；鼠标本身：见第 4 节 |
| Blue Logo | 鼠标 | — | 暂不能做（见第 4 节） |
| 亮度 0–100（每个灯效） | 全部 | 亮度滑块 10–100，现在硬件灯效也生效（应用时设置设备亮度）；以前只影响软件灯效和预览 | **本次新增** |
| 速度 | 全部 | 速度 1–10（键盘 tempo 字节；机身灯 tempo 字节） | 已有（快慢方向待实测） |
| 时长 | 全部 | 时长 1–10 → 机身灯动作的 time 字节（脉冲、渐变、呼吸、单色波、双色波） | **本次新增**（键盘 v5 没有这个参数） |
| 方向 / 角度 | 全部 | 软件波的方向开关（从第一个灯区流向最后一个，或反过来） | 软件：**本次新增**；硬件波的方向和任意角度：暂不能做 |
| 颜色数量 | — | 0 / 1 / 2 色（键盘 color mode 1/2/3） | 已有 |
| 系统照明模式：变亮 / 变黑 / 变暗 | 全局 | 照明模式：正常 / 调暗 / 关闭（调暗 = 正常亮度的 30%，关闭 = 亮度 0；当前灯效不变；电源键灯不动；切回"正常"即恢复） | **本次新增** |
| 选择所有设备 | 全局 | 灯效页"应用到"的勾选框 | 已有 |
| 自定义颜色槽、预设颜色 | 全局 | 颜色选择器 | 部分：没有可保存的色板 |
| 命名 AlienFX 预设（保存 / 取消） | 全局 | 只记住最后一次应用的灯效和参数 | 暂不能做（计划中） |
| 每个游戏自动切换灯光 | 全局 | — | 暂不能做 |
| 按游戏封面颜色生成灯光主题 | 全局 | — | 暂不能做 |
| 隐藏模式（关灯 + 安静散热） | 全局 | 照明模式"关闭"只管灯光 | 部分：故意不联动散热 |

## 3. 本次在 NightGlow 里新增的内容

代码在 `src/NightGlow/Core/Lighting/`（`Effects.cs`、`EffectEngine.cs`、`PreviewRenderer.cs`、`LightingService.cs`）和 `src/NightGlow/Pages/EffectsPage.*`。

1. **默认蓝**：一键设成蓝色静态灯光，不弹颜色选择。键盘用 v5 static，机身灯用 color 动作。
2. **软件双色波**：两种颜色沿灯区顺序流动，用于没有硬件波浪的机身灯。和软件彩虹波一样，需要先在"灯光"页给灯区命名（至少 2 个）。
3. **方向**：软件彩虹波和软件双色波可以反向流动。默认从第一个灯区流向最后一个；原来的软件彩虹波是反着流的，现在统一了。
4. **时长**：机身灯（API v4）逐灯动作的 time 字节，原来固定是 7。时长 4 对应 7，保持旧行为；刻度要等硬件实测。
5. **亮度对硬件灯效生效**：应用硬件灯效时，把设备亮度设成滑块的值。软件灯效本来就按亮度缩放颜色，所以设备亮度设成 100%，避免叠加两次变暗。
6. **照明模式**：正常 / 调暗 / 关闭，作用于所有设备，不改当前灯效。重新应用任何灯效都会回到"正常"。

## 4. 暂不能做

- **610M 鼠标**：AWCC 通过 2.4GHz 接收器控制它。alien-tools 能不能经过接收器控制这只鼠标还没有验证，所以鼠标专属的 Color Wave、Blue Logo 暂时不做。
- **硬件波浪的方向和角度**：alien-tools 给 v5 键盘发整机效果时，命令里只有效果号、速度、颜色模式和两种颜色，没有方向字节。
- **键盘的时长**：v5 整机效果没有这个参数。
- **命名预设、按游戏切换、封面取色**：需要单独设计（预设存储、游戏检测），这次不做。
- **按键反应、音频、温度、电源状态灯光**：AWCC 在这台机器上也没有。alien-tools 的 GUI 有基于事件的灯光，以后可以作为软件功能考虑。
- **"闪烁"的确切行为**：要在 AWCC 里实际切换到这个效果才能看到，这次没有做。

## 5. 待硬件实测

核心库（`nightglow_core.dll`）编译出来以后再确认：
