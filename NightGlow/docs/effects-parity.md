# 灯效对照：AWCC → NightGlow

调查日期：2026-11-27（两轮）。机器：Alienware x16 R2 笔记本，外加一只 Alienware 610M 无线鼠标（2.4GHz 接收器）。

**调查方法（只看不改）：** 打开厂商控制中心（AWCC）的 AlienFX 灯光页，读取界面上能看到的内容。

- **允许的操作：** 点选设备、区域和按键，打开下拉菜单，切换视图。
- **读名称的方式：** 灯效名称通过 Windows 无障碍接口（UI Automation）读取，只展开和收起列表，没有选中其他项。
- **没做的事：** 没有切换灯效，没有保存预设，没有改任何设置（包括散热和性能）。最后点"取消"退出编辑器。

下面都是自己的话，没有复制 AWCC 的代码、图片、图标或声音。

## 1. 区域与彩虹波

### 怎么进入区域选择

1. AlienFX 页默认是"系统"总览，只有笔记本和鼠标两张图。单击只能选整台设备，或者点"选择所有设备"。
2. **双击笔记本图片**，进入设备视图。顶部有 4 个标签：全部设备、笔记本机身、键盘、鼠标。键盘标签的提示是"Alienware X16 R2 Cherry Mechanical AI KB"。
3. 图片下方是一排"选择要进行配置的灯效区域"复选框，可以同时勾多个。一个区域都没勾时，右侧的灯效面板是灰的。

### 机身（笔记本标签）

区域复选框：**所有区域、Touchpad、Alien Head、Stadium**。左侧缩略图可以在两个视角之间切换。

**顶视图：**
- **Touchpad**：触控板，灯 ID 062。
- **Power Button**：电源键，灯 ID 060。图上有标注，但没有单独的复选框。

**背视图：**
- **Alien Head**：屏幕背面的徽标，灯 ID 061。
- **Stadium**：机身背部 I/O 接口一圈的环形灯带（就是"背板环形灯带"）。
  - AWCC 在环上标了 **4 个点**：Stadium Top Left / Top Right / Bottom Left / Bottom Right，也就是把环画成四个角、4 段。
  - 对应的灯 ID 是 000、003、030、033。哪个 ID 对哪个角没有逐一核对；"Top Left"的名称是按对称推断的，其余三个看过提示文字。

**每个区域能选的灯效：**

| 选中的区域 | 灯效列表（AWCC 下拉列表顺序） |
|---|---|
| Stadium（环形灯带） | 变形、脉冲、颜色、闪烁、频谱、扫描仪、循环、Rainbow Wave Stadium、Rainbow Loop Stadium |
| Touchpad | 变形、脉冲、颜色、闪烁、频谱、Rainbow Wave Touchpad |
| Alien Head | 变形、脉冲、颜色、闪烁、频谱 |
| 所有区域 | 变形、脉冲、颜色、闪烁、频谱、彩虹波动、静态默认蓝色 |

环形灯带独有四个灯效：扫描仪、循环、Rainbow Wave Stadium、Rainbow Loop Stadium。从名字看，"Rainbow Loop Stadium"是彩虹沿环绕圈，但没看到实际动画。

### 键盘（键盘标签）

- **单键 RGB：** 界面画出了每一个键，可以单独点选。试过点 W，只有 W 被框选。
- **快捷分组复选框：** 所有键、功能键、数字、QWER、WASD。
- **单键只能设颜色：** 只选一个键时，灯效下拉框是灰的；选一组键（比如所有键）才能选灯效。
- **选所有键时的灯效：** 闪烁、频谱、彩虹波动、跑马灯（霹雳游侠）、静态默认蓝色、颜色。
- 键盘另有"按键绑定"标签（按键和宏），和灯光无关，没打开。

### 鼠标（鼠标标签）

只有一个区域（底部徽标）。另有"按键绑定"和"设置"两个标签。

### 彩虹波：方向、速度、颜色、同步

**这些都没看到。** 方向、速度档位、颜色选择这些控件，只有在编辑器里把灯效切换成"彩虹波动"（或环形灯带的 Rainbow 灯效）之后才会出现。切换会在灯上实时预览，这次规定不切换，所以没做。

目前能确定的：
- **方向：** AWCC 每个灯效的数据里都有"方向"和"角度"两个字段（见第 2 节），说明它的波浪有方向或角度的概念。具体是左→右、右→左，还是任意角度，没看到。
- **环上是否绕圈走：** 只能从名字"Rainbow Loop Stadium"推测是绕圈，没看到动画。
- **键盘和灯环是否同步：** 同时选中多个区域时，列表里有"彩虹波动"。但动画是否连成一片、节奏是否一致，要应用之后看实际灯光才知道，这次没有应用。

### 水滴、涟漪、按键反应

**AWCC 在这台机器上没有这类灯效。** 下面这些选择的灯效列表里，都没有涟漪、按键反应或任何"按下才触发"的灯效：

- 键盘的所有键
- Stadium、Touchpad、Alien Head、所有区域
- 鼠标

AWCC 的数据里有"触发事件"字段，但当前都是"静态"，界面上也没有可选的事件。所以 NightGlow 的水滴涟漪 `sp-ripple` 是 AWCC 没有的功能。

## 2. 在 AWCC 里看到的其他灯光功能

### 系统总览里的设备

- **笔记本**：总览里整台笔记本是一个可选目标。要按区域选，得双击进入设备视图（见第 1 节）。
- **610M 鼠标**：显示连接方式（2.4GHz）和电量。
- **"选择所有设备"按钮**：一次编辑全部设备。

### 总览里每个设备的灯效列表

| 设备 | 灯效（AWCC 下拉列表顺序） |
|---|---|
| 笔记本（整机） | 变形、脉冲、颜色、闪烁、频谱、彩虹波动、静态默认蓝色（7 个） |
| 610M 鼠标 | 变形、脉冲、颜色、闪烁、频谱、静态默认蓝色、Color Wave、Blue Logo（8 个；最后两个在中文界面里没有翻译） |

鼠标没有"彩虹波动"，多出"Color Wave"和"Blue Logo"。

### 参数

- **当前灯效"颜色"的编辑面板：**
  - 1 个颜色：色轮，加上红、绿、蓝三个输入框（各 0–255）。
  - 12 个自定义颜色槽，12 个预设颜色。
  - 亮度滑块（0–100）。
- **效果数据里的其他字段：** 通过无障碍接口读到，当前效果除了颜色和亮度，还带着触发事件（当前是"静态"）、速度、时长、方向、角度。所以 AWCC 的灯效模型支持速度、时长、方向和角度。
- **没看到：** 具体哪个灯效显示哪些滑块、范围多少。这要在编辑器里切换到那个灯效才能看到；换效果的操作也被自动安全检查拦下了。

### 全局功能

- **系统照明模式：** 三选一，"变亮 / 变黑 / 变暗"，当前是"变亮"。
- **AlienFX 预设：** 预设有名字（当前是"系统默认"），编辑后选"保存预设"或"取消"。
- **设置 › 全局预设 › 灯光预设开关：**
  - "系统"：所有场景用同一套灯光（当前设置）。
  - "每个游戏"：检测到游戏时自动切换灯光；默认按游戏封面的主色自动生成一套灯光。
- **设置 › 隐藏模式：** 一键关掉所有 AlienFX 灯光，同时切到安静的散热预设。当前是关闭。
- **库（游戏库）：** 按游戏绑定预设的入口。

### 这台机器上没有的

- 按键反应、涟漪、随音乐变化、随温度变色：所有区域的灯效列表里都没有。
- 按电源状态（接电 / 电池 / 睡眠）分别设灯光：没有单独选项，只有上面的系统照明模式和隐藏模式。

## 3. 对照表

NightGlow 一栏以当前 dev-ui 为准。

| AWCC 灯效 / 功能 | 区域 / 设备 | NightGlow 对应 | 状态 |
|---|---|---|---|
| 颜色 | 全部 | 静态 `static`（硬件：键盘 v5 static；机身灯 color 动作） | 已有 |
| 变形 | 机身各区域、鼠标 | 渐变 `morph`（硬件：键盘 v5 morph=9；机身灯 morph 动作；2 色） | 已有 |
| 脉冲 | 机身各区域、鼠标 | 脉冲 `pulse`（硬件：键盘 v5 pulse=8；机身灯 pulse 动作） | 已有 |
| 闪烁 | 全部 | 最接近的是脉冲 `pulse` 或呼吸 `breathing`（硬件） | 近似：没看到 AWCC 的实际动画，不能确定对应哪一个 |
| 频谱 | 全部 | 光谱循环 `spectrum`（硬件：键盘 v5 rainbow=14；机身灯 rainbow 动作） | 已有 |
| 彩虹波动 | 键盘、所有区域 | 彩虹波 `sp-wave`（软件，选中的区域连成一片，可调方向）；硬件彩虹波 `rainbow-wave` | 已有 |
| Rainbow Wave Stadium / Rainbow Loop Stadium | 环形灯带 | 彩虹波 `sp-wave`，作用在灯环区域 | 已有（软件）；AWCC 的实际走向没看到 |
| Rainbow Wave Touchpad | 触控板 | 彩虹波 `sp-wave`，作用在触控板所在区域 | 已有（软件） |
| 扫描仪 | 环形灯带 | 键盘有硬件弹跳 `bounce` / 激光 `laser`；灯环上没有对应 | 未做 |
| 循环 | 环形灯带 | 光谱循环 `spectrum` 或颜色循环 `sw-cycle` 最接近 | 近似：没看到 AWCC 的实际动画 |
| 跑马灯（霹雳游侠） | 键盘 | 激光 `laser` / 弹跳 `bounce`（键盘硬件） | 近似 |
| 静态默认蓝色 | 全部 | 默认蓝 `default-blue`（硬件静态，固定蓝色；色值是 NightGlow 自己选的） | 已有 |
| Color Wave | 鼠标 | 双色波 `dual-wave`（键盘硬件）；鼠标本身见第 5 节 | 部分 |
| Blue Logo | 鼠标 | — | 暂不能做（见第 5 节） |
| 涟漪 / 按键反应 | （AWCC 没有） | 水滴涟漪 `sp-ripple`（软件） | NightGlow 独有 |
| 按区域选择（所有区域、Touchpad、Alien Head、Stadium；键盘分组和单键） | 全部 | 区域选择由 a83feef 实现 | 已有（详情见那次提交） |
| 亮度 0–100（每个灯效） | 全部 | 亮度滑块，硬件灯效也生效（应用时设置设备亮度） | 已有 |
| 速度 | 全部 | 速度 1–10（键盘 tempo 字节；机身灯 tempo 字节） | 已有（快慢方向待实测） |
| 时长 | 全部 | 时长 1–10 → 机身灯动作的 time 字节 | 已有（键盘 v5 没有这个参数） |
| 方向 / 角度 | 全部 | 软件波可调方向 | 软件：已有；硬件波的方向和任意角度：暂不能做 |
| 系统照明模式：变亮 / 变黑 / 变暗 | 全局 | 照明模式：正常 / 调暗 / 关闭（调暗 = 正常亮度的 30%，关闭 = 亮度 0；当前灯效不变；电源键灯不动） | 已有 |
| 选择所有设备 | 全局 | 灯效页"应用到"的勾选框 | 已有 |
| 自定义颜色槽、预设颜色 | 全局 | 颜色选择器 | 部分：没有可保存的色板 |
| 命名 AlienFX 预设（保存 / 取消） | 全局 | 只记住最后一次应用的灯效和参数 | 暂不能做（计划中） |

| 隐藏模式（关灯 + 安静散热） | 全局 | 照明模式"关闭"只管灯光 | 部分：故意不联动散热 |

## 4. 第一轮对照时加进 NightGlow 的内容（3d62461）

代码在 `src/NightGlow/Core/Lighting/` 和 `src/NightGlow/Pages/EffectsPage.*`。

1. **默认蓝**：一键设成蓝色静态灯光，不弹颜色选择。键盘用 v5 static，机身灯用 color 动作。
2. **时长**：机身灯（API v4）逐灯动作的 time 字节，原来固定是 7。时长 4 对应 7，保持旧行为；刻度要等硬件实测。
3. **亮度对硬件灯效生效**：应用硬件灯效时，把设备亮度设成滑块的值。软件灯效本来就按亮度缩放颜色，所以设备亮度设成 100%，避免叠加两次变暗。
4. **照明模式**：正常 / 调暗 / 关闭，作用于所有设备，不改当前灯效。重新应用任何灯效都会回到"正常"。
5. **软件双色波和软件波的方向开关**：后来在区域和空间灯效提交（a83feef）里，合并进了彩虹波 `sp-wave` 的方向设置。

## 5. 暂不能做

- **610M 鼠标**：AWCC 通过 2.4GHz 接收器控制它。alien-tools 能不能经过接收器控制这只鼠标还没有验证，所以鼠标专属的 Color Wave、Blue Logo 暂时不做。
- **硬件波浪的方向和角度**：alien-tools 给 v5 键盘发整机效果时，命令里只有效果号、速度、颜色模式和两种颜色，没有方向字节。
- **键盘的时长**：v5 整机效果没有这个参数。
- **命名预设、按游戏切换、封面取色**：需要单独设计（预设存储、游戏检测），这次不做。
- **音频、温度、电源状态灯光**：AWCC 在这台机器上也没有。alien-tools 的 GUI 有基于事件的灯光，以后可以作为软件功能考虑。
- **AWCC 波浪的确切行为**（方向选项、速度档位、颜色选择、灯环上是否绕圈、键盘和灯环是否同步），以及"闪烁""扫描仪""循环"的样子：都要在 AWCC 里实际切换到那个灯效才能看到，这次没有做。

## 6. 待硬件实测

核心库（`nightglow_core.dll`）编译出来以后再确认：

- 速度字节是越小越快还是越大越快；时长字节的实际刻度。
- 对 v5 键盘设置设备亮度，能不能正常调亮度（照明模式也靠这个）。
- 默认蓝在键盘和机身灯上的实际颜色。
- 环形灯带 4 个灯 ID（000、003、030、033）各对应哪个角。
